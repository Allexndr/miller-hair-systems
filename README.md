# MILLER Premium Hair Systems - Лендинг

Современный лендинг для салона париков MILLER с винтажным дизайном и золотыми акцентами.

## Особенности

- 🎨 **Винтажный дизайн** с золотыми акцентами в стиле "Old Money"
- 📱 **Полностью адаптивный** для всех устройств
- 🧪 **Интерактивный тест** для выбора идеального изделия
- 💰 **Каталог товаров** с ценами и опциями
- ⚡ **Быстрая загрузка** и оптимизированная производительность
- 🔗 **Интеграция с Telegram** для консультаций

## Структура сайта

### 7 основных блоков:

1. **Hero Section** - Главный экран с логотипом и призывом к действию
2. **Консультация** - Кнопки "Пройти тест" и "Личная консультация"
3. **Каталог товаров** - Все изделия с ценами и описаниями:
   - Системы волос (30-35см, 40-45см, 50-55см, 60-65см)
   - Накладки на макушку (Мини, Макси, Глубокая)
   - Аксессуары (Хвост, Челка, Пучок, Краб)
4. **Факты о компании** - 5 ключевых преимуществ
5. **Отзывы клиентов** - Социальные доказательства
6. **Этапы работы** - Процесс заказа в 3 шага
7. **FAQ** - Часто задаваемые вопросы

## Установка и запуск

1. Склонируйте репозиторий или скачайте файлы
2. Откройте `index.html` в браузере
3. Для разработки можно использовать локальный сервер:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js
   npx serve .
   ```

## Настройка

### Изменение контактной информации
В файле `index.html` найдите секцию контактов и обновите:
- Номер телефона
- Telegram-ссылку
- Адреса офисов

### Добавление новых товаров
В файле `script.js` обновите объект `basePrices` в функции `calculateRecommendation()`.

### Изменение цветовой схемы
В файле `styles.css` измените CSS-переменные в секции `:root`.
